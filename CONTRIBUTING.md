# Contributing to RRR

First off, thank you for considering contributing to RRR! It's people like you that make RRR an incredible educational platform.

## Code of Conduct

By participating in this project, you agree to abide by our Code of Conduct. We expect all contributors to maintain a respectful, inclusive, and harassment-free environment.

## How Can I Contribute?

### Reporting Bugs
If you find a bug, please create an issue on GitHub. Include:
1. Steps to reproduce the bug.
2. Expected behavior.
3. Actual behavior.
4. Screenshots or console errors if applicable.

### Suggesting Enhancements
Have an idea for a new feature, a new algorithm, or a new visual mode? Open a feature request issue! Explain why the enhancement would be useful and how it aligns with the premium aesthetic of RRR.

### Pull Requests
1. Fork the repository and create your branch from `main`.
2. Ensure your code follows the existing style guidelines (Obsidian Black & Gold theme, Glassmorphism, Tailwind).
3. If you've added an algorithm, ensure it integrates properly with the event-driven `sortEngine`.
4. Ensure your code is fully typed with TypeScript.
5. Make sure your commit messages are descriptive and follow conventional commits format.
6. Issue a Pull Request and provide a clear description of your changes.

## Development Setup

See the [README.md](README.md) for instructions on setting up the local development environment.

Thank you for contributing!
