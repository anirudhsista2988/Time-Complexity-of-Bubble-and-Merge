# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-06-10

### Added
- **Core Sorting Engine**: Mathematical frame-by-frame evaluation for 10 algorithms (Bubble, Selection, Insertion, Merge, Quick, Heap, Counting, Radix, Bucket, Shell).
- **Cinematic Homepage**: Particle network background, live sorting canvas overlay, and 3D tilting algorithm trading cards.
- **Sort Lab**: Multi-mode visualization engine supporting Bars, Skyline, Circular, Particle, and Matrix modes.
- **AI Explain Engine**: Live running commentary mapping algorithm states to human-readable steps.
- **Race Arena**: F1-style multi-algorithm competitive racing with live rankings and telemetry tracking.
- **Analytics Terminal**: Bloomberg-style real-time charting dashboard using Chart.js to map algorithm growth rates up to n=1000.
- **Learning Center**: Theory, pseudocode, and usage context for all included algorithms.
- **Code Studio**: 1-click copyable implementations in 6 languages.
- **Complexity Universe**: Clickable O-notation visualizer.
- **Interview Master**: FAANG question bank and complexity cheat sheets.
- **Design System**: Global Obsidian Black and Champagne Gold Tailwind theme utilizing intensive glassmorphism.
